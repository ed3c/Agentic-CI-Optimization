# Agentic CI Optimization — reusable professional capability

Read [mathematics and quality](../../../docs/contracts/ci-optimization-mathematics-and-quality.md)
before proposing modifications to any repository's CI or tests. Read
[five trade-offs](references/five-tradeoffs.md) only when applicable.
Consult [original research](../../../docs/research/source-index.md)
and [tool catalog](../../../docs/research/tool-catalog.md) when needed.

## Trigger and inputs

Apply when latency, cost, unnecessary verification, test value, queue
capacity, source/consumer selection, or agent retry loops can materially
affect the existing Goal. Consume original Scope, authority, current
Session, repository/base/HEAD, run/attempt, original selection, source-bound
independent contracts, actual receipts and the original continuation.

## Method

1. Observe existing Provider and Test Owner receipts. Separate supported,
   missing, contradicted and invalidated evidence. Never fill UNKNOWN with 0.
2. Diagnose the earliest causal bottleneck. Use task DAG, queueing, Amdahl,
   or test-value analysis only under their applicable assumptions.
3. Compare Keep, Rewrite, Consolidate, On-demand, Reschedule and Delete
   CANDIDATES using independent Oracle, fault and legal neighbor,
   actual demand, source freshness and verified replacement evidence.
4. Propose bounded baseline/treatment experiments and negative controls.
   Synthetic examples are not measured speedups.
5. Return findings to the original Outer/Session for semantic judgment.
   The target original Test Manager selects/executes; original Provider
   confirms effects. Poteto only works inside admitted write scope.
6. Optional ub-mode final audit only after the full candidate's original
   required functional acceptance. No new scheduler or parallel ledger.

Output evidence, limitations, cohort, candidates, falsifiers, actual results
or UNKNOWN, original Owner and original legal next. Stop at NOOP when
nothing decision-changing remains. Saved instructions do not prove native
Host activation or Consumer compliance.
